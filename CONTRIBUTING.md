# Panduan Kontribusi (Contributing Guidelines)

Terima kasih telah tertarik untuk berkontribusi pada **nuNox_servis**! Kami menyambut baik segala bentuk kontribusi, mulai dari perbaikan bug, penambahan fitur, hingga perbaikan dokumentasi.

## Cara Berkontribusi

1. **Fork** repositori ini.
2. Buat branch baru untuk fitur atau perbaikan Anda (`git checkout -b fitur-keren-anda`).
3. Lakukan perubahan pada kode. Pastikan untuk mengikuti gaya penulisan kode (code style) yang sudah ada.
4. Uji perubahan Anda. Jika memungkinkan, jalankan pengujian E2E (End-to-End) lokal dengan perintah `npm run test:e2e`.
5. **Commit** perubahan Anda (`git commit -m "feat: menambahkan fitur keren"`). Gunakan konvensi penamaan commit yang deskriptif.
6. **Push** ke branch di repositori fork Anda (`git push origin fitur-keren-anda`).
7. Buat **Pull Request (PR)** ke branch `main` repositori ini. Berikan penjelasan yang jelas mengenai apa yang Anda ubah dan mengapa.

## Melaporkan Bug (Bug Reports)

Jika Anda menemukan bug, silakan buat [Issue baru](../../issues/new?template=bug_report.md) dengan menggunakan template laporan bug. Sertakan detail sebanyak mungkin agar kami dapat dengan mudah memverifikasi dan mereproduksi bug tersebut.

## Meminta Fitur (Feature Requests)

Punya ide brilian untuk aplikasi ini? Silakan ajukan melalui [Issue Permintaan Fitur](../../issues/new?template=feature_request.md). Jelaskan masalah yang ingin Anda selesaikan dan usulan solusi atau fitur Anda.

---
Terima kasih atas waktu dan dedikasi Anda untuk membuat aplikasi ini menjadi lebih baik!
